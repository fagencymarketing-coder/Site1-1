# 1-plus-1.ru — рабочая база проекта

Сайт компании «1+1» (бухгалтерский аутсорсинг, Барнаул). CMS — 1С-Битрикс,
шаблон `/local/templates/main2025/`. Разработку ведут сторонние подрядчики;
здесь хранятся аналитика, решения и задания для них.

## Структура

| Файл | Что внутри |
|---|---|
| `docs/01-cifrovoy-avatar.md` | Цифровой аватар компании: цифры, собственница, позиционирование, клиент, доказательная база, расхождения, конкуренты, тон |
| `docs/02-tech-audit-2026-10.md` | Технический аудит сайта на 27.10.2026: 500-е, дубли, canonical, заголовки, объём текстов, перелинковка, микроразметка |
| `specs/01-drugie-uslugi.md` | ТЗ подрядчику: блок «Другие услуги», карта из 116 ссылок, чеклист приёмки |
| `specs/02-keysy-i-stati-na-glavnoy.md` | Блок статей на главной, варианты размещения, компонент |
| `specs/03-teksty-buhuslugi.md` | Уникальные тексты на страницы бухуслуг: структура, очередь, промт для контент-чата |
| `specs/04-razvesti-finkonsalting.md` | Убрать дублирование финконсалтинга из ветки бухуслуг |

## Приоритеты

1. Починить 500-е (`/news/`, `/bukhgalterskoe-soprovozhdenie/`, `/prochie-uslugi/`), вычистить sitemap
2. Склеить дубли через 301, добавить `rel="canonical"`
3. Заменить дивы-заголовки на `h2`/`h3` в шаблоне
4. Блок «Другие услуги» (задача 1)
5. Блок статей на главной (задача 2)
6. Развести бухуслуги и финконсалтинг (задача 4)
7. Уникальные тексты на страницы услуг (задача 3)
